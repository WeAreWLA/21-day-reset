# Testimonials

Drop your member testimonials here and they'll be picked up by the
guide builder.

## `before-after/`

Member before / after photos. Use clear, comparable images and crop
them roughly portrait (a tall rectangle).

- File format: `.jpg` / `.jpeg` / `.png`
- Suggested size: at least 600px tall
- Recommended count: 8 (for the two "WLA Members Results" pages)
- Filename order is alphabetical, so name them as you want them to
  appear, e.g. `01-vicky.jpg`, `02-laura.jpg`, …

## `screenshots/`

Written testimonials — screenshots of Facebook posts, reviews, etc.

- File format: `.jpg` / `.jpeg` / `.png`
- Suggested size: roughly square or short landscape
- Recommended count: 6 (for the "Our Community Success" page)
- Same alphabetical filename ordering.

After adding files, rebuild the guide:
`python3 build_fat_loss_reset.py`
