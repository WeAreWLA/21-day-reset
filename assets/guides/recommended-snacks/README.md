# Recommended Snack Product Images

Drop the product packshot images here. Filenames are matched by
substring (case-insensitive) against the snack name, so you can name
them however you like as long as part of the brand name appears.

Suggested names (any of these will work):

| Snack                                       | Filename starts with |
|---------------------------------------------|----------------------|
| Lindt Dark Chocolate (70%+ cocoa)           | `lindt`              |
| Propercorn Sweet & Salty                    | `propercorn`         |
| Nakd Bars                                   | `nakd`               |
| Deliciously Ella Hazelnut Bites             | `hazelnut`           |
| Deliciously Ella Dipped Almonds             | `almonds`            |
| Nush Strawberry Yoghurt & Berries           | `nush`               |
| Bear Fruit Rolls                            | `bear`               |
| Deliciously Ella Oat Bars                   | `oat-bars`           |

File formats: `.jpg`, `.jpeg`, `.png`.
